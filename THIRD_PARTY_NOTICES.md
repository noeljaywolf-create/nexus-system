# Third-party browser dependency

Mozilla PDF.js / pdfjs-dist version 6.4.299, Apache License 2.0.
Source: https://github.com/mozilla/pdf.js
Distribution: https://registry.npmjs.org/pdfjs-dist/-/pdfjs-dist-6.4.299.tgz
Bundled license: web/vendor/pdfjs/LICENSE

The upstream archive SHA-512 integrity was verified before extracting an allowlisted set of viewer modules, worker, character maps, fonts, color profiles and WebAssembly resources. Installation scripts were not run. The local viewer disables evaluation and WebAssembly execution. This dependency has not received an independent security audit in this project. Future releases require dependency review and updates.
